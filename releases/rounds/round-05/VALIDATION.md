## 3. Training runtime invariants

Round 05 validates:

- Parameter values are runtime state, not canonical Graph identity;
- `TrainingState` copies Parameter arrays and marks them read-only;
- SGD returns fresh arrays and does not mutate previous states;
- optimizer targets must be outputs of `Parameter` nodes;
- derivative graph generation occurs once per training run;
- loss must be scalar and finite;
- gradients must be finite and shape-compatible with their runtime Parameter binding;
- identical initial state and configuration reproduce the same loss history and final parameter-state hash;
- canonical Graph semantic hash is unchanged throughout training.

- Legacy `semantic_hash` changes when embedded human `reason` text changes.
- NSM5 bytes do not change for the same persisted manifest when only Human Projection changes.
- `source_projection` and provenance remain outside machine authority.
- Human-projection sidecar hash changes independently from the purified machine hash.
- Extracted projection attachment anchor is stable across text edits.
- NSM5 contains no `DomainText(HUMAN_PROJECTION, ...)`.
- `reason` text is physically absent from the tested NSM5 payload.
- A semantic mutation `Add -> Subtract` changes the purified machine hash.
- NSM5 decode/re-encode is byte-identical.
- Purification re-sorts constraint sets after extraction, preventing human `reason` text from perturbing machine ordering indirectly.
- Fresh `bootstrap_purified_identity_manifest()` produces the same Identity Manifest for legacy projects differing only in Human Projection.
- Existing Identity Manifests are not modified or regenerated by v0.5.

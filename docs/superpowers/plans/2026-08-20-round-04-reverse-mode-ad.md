# NOVA Core Closure Round 04 — Reverse-Mode AD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce and execute deterministic NOVA derivative graphs using language-level reverse-mode AD.

**Architecture:** Add an `autodiff` subsystem that transforms an immutable primal `Graph` into a new derivative `Graph`. VJP rules emit ordinary NOVA operations plus a bounded set of explicit AD primitives executed by both reference runtimes. Finite differences are used only for validation.

**Tech Stack:** Python 3.11+, NumPy, pytest, immutable dataclasses.

**Spec:** `docs/superpowers/specs/2026-08-20-round-04-reverse-mode-ad-design.md`

## Global Constraints

- Do not call external autograd engines.
- Do not mutate the primal graph.
- Preserve deterministic semantic hashes.
- Unknown differentiability must fail explicitly.
- Use only `$...$` and `$$...$$` in Markdown math.
- Preserve UTF-8 without Unicode escape round-trips.

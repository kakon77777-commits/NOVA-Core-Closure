# Round 10 Nova-A AI-Native Graph Construction Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement structured AI-native graph construction through sandboxed, validated, auditable GraphPatch build transactions and seal G4.

**Architecture:** Preserve `GraphPatch` as the sole canonical mutation language. Add an `ai_build` layer that accepts structured build requests, enforces a static sandbox, applies patches only to candidate Projects, independently checks constraints/tests/differentiation obligations, and commits through existing `GraphTransaction` only after preview/commit hash equivalence is proven.

**Tech Stack:** Python 3.11+, dataclasses/enums, hashlib/json, NumPy, existing NOVA GraphPatch/GraphTransaction/diff/runtime/autodiff, pytest.

**Spec:** `docs/superpowers/specs/2026-08-20-round-10-nova-a-g4-design.md`

## Global Constraints

- Runtime version: `0.10.0`.
- Graph schema version remains `0.1.0`.
- No production code without a failing test first.
- AI/build metadata is untrusted input.
- All mutation must lower to existing `GraphPatch`.
- Preview must not mutate the working Project.
- Commit must independently reproduce the preview hashes.
- No arbitrary source evaluation in sandbox tests.
- Local ZIP delivery only; do not push GitHub.

def test_commit_reproduces_preview_hash_and_rollback_restores_base():
    tx = AIBuildTransaction(base_project())
    base_record = tx.record_hash
    candidate = tx.preview(valid_request())
    result = tx.commit(candidate)
    assert result.after_semantic_hash == candidate.candidate_semantic_hash
    assert result.after_record_hash == candidate.candidate_record_hash
    tx.rollback()
    assert tx.record_hash == base_record


def test_stale_candidate_is_refused():
    tx = AIBuildTransaction(base_project())
    first = tx.preview(valid_request())
    tx.commit(tx.preview(second_valid_request()))
    with pytest.raises(AIBuildConflictError):
        tx.commit(first)

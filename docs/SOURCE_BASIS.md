# Source Basis

This repository bootstrap is derived from the recovered NOVA project specifications, principally:

1. `Nova Core Baseline v3.0`
2. `Nova Unified Roadmap v1.0`
3. `Structure Before Text: Nova and the Ontology of Post-Textual Programming Languages`
4. `EML–APL Operator Bridge and Nova Pre-Intermediate Layer`
5. `Dynamic Revealing as a Language-Regulation Demonstrator`

Authority for Core semantic decisions is ordered as:

```text
Nova Core Baseline v3.0
→ Nova Unified Roadmap v1.0
→ explicit extension contracts
→ theoretical / vertical-slice documents
```

The implementation must not silently redefine Core semantics to accommodate an extension.
